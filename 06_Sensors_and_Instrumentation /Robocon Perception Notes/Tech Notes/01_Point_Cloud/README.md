# What Is a Point Cloud?

Unlike a conventional camera, which records pixels, a LiDAR directly measures the spatial position of surrounding objects using laser pulses.

Each reflected laser beam becomes one point in three-dimensional space.

A complete scan therefore consists of a large collection of points, commonly referred to as a **point cloud**.

Each point generally contains information such as

- X coordinate
- Y coordinate
- Z coordinate
- Reflectivity (Intensity)
- Timestamp

These points collectively describe the surrounding environment.

---

# My Observations

One of the first things I noticed was that the indoor environment could already be recognized without any image information.

Walls, pillars, furniture, and surrounding structures naturally emerged from the distribution of points.

Another interesting observation was the coloring mode.

Initially, I assumed the colors represented distance.

After checking the Viewer settings, I realized that the default visualization uses **Reflectivity** instead.

This means the colors indicate how strongly different surfaces reflect laser pulses rather than how far away they are.

Different materials therefore appear with different colors even when they are located at similar distances.

This was my first intuitive understanding that LiDAR provides much richer geometric information than ordinary cameras.

# Why Is This Important?

Today's work also helped me understand the role of point clouds within the robotic perception pipeline.

At first, I thought point cloud visualization was the final goal.

However, I gradually realized that visualization is only a debugging tool.

The actual workflow is

```
Livox MID360
        │
        ▼
Raw Point Cloud
        │
        ▼
ROS2 Driver
        │
        ▼
RViz
        │
        ▼
FAST-LIO
        │
        ▼
Localization & Mapping
        │
        ▼
Navigation
```

The point cloud itself is only the beginning.

Every localization, mapping, obstacle avoidance, and navigation algorithm ultimately starts from these raw spatial measurements.

Understanding point clouds is therefore the first prerequisite before studying robotic perception algorithms.
