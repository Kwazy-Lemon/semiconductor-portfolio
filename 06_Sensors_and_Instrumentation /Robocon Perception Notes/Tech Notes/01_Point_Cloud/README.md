# What is a Point Cloud?

Unlike a camera, which records images, a LiDAR measures the distance between the sensor and surrounding objects using laser pulses.

Each measurement becomes a point in 3D space.

A complete scan therefore consists of thousands of points forming a **Point Cloud**.

Each point typically contains:

| Field | Description |
|-------|-------------|
| X | X coordinate |
| Y | Y coordinate |
| Z | Z coordinate |
| Intensity / Reflectivity | Laser reflection strength |
| Timestamp | Acquisition time |

---

# My Observations

## Dense Point Distribution

The indoor environment can be reconstructed from individual laser returns.

Walls, pillars, and surrounding structures are clearly visible.

---

## Reflectivity Coloring

Different colors represent different reflectivity values.

High-reflectivity materials appear brighter, while low-reflectivity surfaces appear darker.

---

## Spatial Geometry

The point cloud directly preserves the geometric structure of the environment without converting it into images.

This makes it highly suitable for mapping and localization.

---

# Engineering Significance

Point clouds are the primary input for many robotic perception algorithms.

For example,

```
Livox MID360
        │
        ▼
Point Cloud
        │
        ▼
ROS2
        │
        ▼
RViz
        │
        ▼
FAST-LIO
        │
        ▼
SLAM / Navigation
```

Understanding point cloud data is therefore the first step before studying robotic perception algorithms.
