# What is ROS2?

ROS2 (Robot Operating System 2) is an open-source middleware framework designed for robotics.

Rather than being an operating system itself, ROS2 provides a communication infrastructure that allows different robotic software modules to exchange information efficiently.

It enables sensors, perception algorithms, localization systems, navigation modules, and visualization tools to work together.

---

# Why ROS2?

Modern robots contain many independent software components.

For example,

- LiDAR Driver
- IMU Driver
- Camera Driver
- FAST-LIO
- Localization
- Navigation
- Motion Controller
- RViz

Without a communication framework,

each module would need to communicate directly with every other module, making the system difficult to develop and maintain.

ROS2 standardizes communication between these modules.

# Core Concepts

## Node

A Node is an independent program performing a specific function.

Examples include

- LiDAR Driver
- FAST-LIO
- RViz
- Navigation

A robotic system usually consists of many Nodes running simultaneously.

---

## Topic

A Topic is a communication channel used to exchange messages between Nodes.

For example,

```
LiDAR Driver

↓

/livox/lidar

↓

FAST-LIO
```

The LiDAR driver continuously publishes point cloud data,

while FAST-LIO subscribes to the same topic for localization.

---

## Publisher and Subscriber

ROS2 communication follows a publish-subscribe model.

```
Publisher

↓

Topic

↓

Subscriber
```

For example,

```
Livox Driver

↓

/livox/lidar

↓

FAST-LIO
```

The publisher continuously sends messages,

while the subscriber receives and processes them.

---

## Message

A Message is the actual data transmitted through a Topic.

Examples include

- PointCloud2
- Image
- LaserScan
- IMU
- Odometry
- TF

Different robotic modules exchange these standardized message types.

# RViz in ROS2

One important visualization tool within the ROS2 ecosystem is RViz.

RViz allows developers to visualize

- Point Clouds
- Robot Pose
- Maps
- TF Frames
- Laser Scans
- Planned Paths

Instead of performing localization,

RViz simply displays the information generated by other ROS2 Nodes.
