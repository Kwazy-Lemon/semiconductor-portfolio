# Livox MID360 Official Dataset Exploration
## Objective

Learn how Livox MID360 records and visualizes point cloud data.

## Dataset

- Source: Official Livox MID360 Indoor Dataset
- Format: .lvx2

## Environment

- Windows 11
- Livox Viewer 2
