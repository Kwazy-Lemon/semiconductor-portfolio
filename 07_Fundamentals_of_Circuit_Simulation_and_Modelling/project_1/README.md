# Project 1 — ECSE 472

This folder contains the implementation and documentation for ECSE 472 Deliverable 1.

## Scope

- Read a circuit netlist written from a supplied circuit diagram.
- Identify circuit nodes and supported elements.
- Construct Modified Nodal Analysis (MNA) matrices.
- Solve linear DC circuits using Python.
- Validate results against hand calculations.

## Planned Files

- `mna_dc.py` — main Python implementation.
- `circuits/` — sample netlists for testing.
- `tests/` — validation cases and expected results.
