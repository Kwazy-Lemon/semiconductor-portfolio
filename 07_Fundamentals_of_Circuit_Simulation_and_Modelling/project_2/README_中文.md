`project_1` 保留原样，作为项目一的独立版本。`project_2` 从项目一的 `mna_dc.py` 扩展而来，包含完整代码，可以单独运行，不需要修改或导入项目一。

## 两份代码之间的关系

| 部分 | 项目二如何处理 |
| --- | --- |
| 项目一九类元件 | 全部保留，包括四种受控源，以及直流下的电容开路、电感短路 |

项目二的核心是反复调用线性求解器：根据当前电压计算二极管印章，组装雅可比矩阵，求修正量，更新工作点，再检查原始非线性方程是否满足。

## 二极管印章

按题目固定 `Is = 1e-15 A`，`Vt = 0.025 V`，理想因子为 1：

```text
Vd  = Va - Vc
Id  = Is * (exp(Vd / Vt) - 1)
gd  = (Is / Vt) * exp(Vd / Vt)
Ieq = Id - gd * Vd
```

在当前工作点，二极管等效为电导 `gd` 与从阳极流向阴极的电流源 `Ieq` 并联。矩阵对角位置加 `gd`，交叉位置减 `gd`；右端向量在阳极减 `Ieq`，在阴极加 `Ieq`。接地端点没有对应的未知量，应跳过相应行列。

代码中的 `build_mna(elements, operating_point)` 负责填入该印章，`solve_dc()` 负责迭代。求修正量采用 `J*delta = -F(x)`，它与无阻尼时直接求解线性化方程 `J*x_new = z` 等价。

## 运行和验证

在本目录执行：

```text
python start_code.py
python mna_dc.py circuits/linear_divider.cir
python -B -m unittest -v test_mna_dc.py
```

共 22 项自动化测试，包含项目一所有九类元件的回归检查，以及二极管的正向、反向、多二极管、受控源驱动和异常情况。

题目二极管电路的结果：

```text
V(n1) = 1 V
V(n2) = 0.267314409 V
I(D1) ≈ 0.00534628818 A
I(Vin) ≈ -0.00534628818 A
```

本程序把电压源电流的正方向定义为从第一个节点流向第二个节点。电源向外供电时，这个电流为负；题目中的 `IE = 0.0053 A` 对应它的大小，或使用了相反的参考方向。

在 Google Colab 中的具体运行步骤和网表格式，见 [README](README.md)。如果已在同一个 Colab 会话中导入项目一的 `mna_dc`，建议重启运行时后再导入项目二，避免同名模块缓存造成混淆。
