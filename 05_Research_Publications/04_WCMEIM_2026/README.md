## Overview

This research proposes a sensitivity-guided sequential framework for compact MOSFET parameter extraction under multi-bias operating conditions. By introducing normalized sensitivity analysis into the extraction workflow, the proposed method determines the priority of parameter estimation according to each model parameter's influence on the device characteristics. The framework aims to improve extraction efficiency, reduce parameter coupling, and establish a more systematic parameter extraction strategy for compact MOSFET models. :contentReference[oaicite:0]{index=0}
